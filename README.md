
# Student Event Registration Formatter

## Description
This Python program collects student information
and event details, then displays a clean and
formatted registration summary.

## Features
- Accepts student first and last names.
- Formats the full name properly.
- Converts the name and section to uppercase.
- Formats the event title.
- Displays the event date in a readable format.
- Displays the programming language and features used.

## Language Used
Python

## String Methods Used
- strip()
- title()
- upper()

## Date/Time Feature Used
- datetime

## Sample Output
